# Meta Pulse v0.2.104

## 修复模型榜管理页响应截断

- 修复 Answer 的 Brotli 中间件与 Gin `c.Data` 对 `Content-Length` 的处理冲突。浏览器请求原先可能收到 HTTP 200，但响应体被反向代理判为提前结束，模型榜管理页因此显示服务不可用。
- 管理 BFF 现在由当前响应写入器决定压缩后的传输 framing；保留管理员校验、上游 JSON 校验和错误投影。
- 增加 Answer 同版本 Brotli、真实 HTTP 服务和反向代理测试，验证 identity 与 Brotli 两种响应均可完整读取。
