# Meta Pulse v0.2.67

## 更新内容

- 修复 `/topics` 与 `/topics?view=tags` 的搜索收录障碍：Google 渲染时，公开 `siteinfo` 被 robots.txt 阻止，目录加载失败后错误页写入 `noindex, follow`。现补齐 `siteinfo`、`tag`、`tags` 的精确抓取规则，覆盖类别、介绍、标签分页及共享导航。
- 保留登录、注册、找回密码、个人权益、状态及其他私有页面的 noindex；公开 JSON 接口本身仍 noindex，相似前缀和子路径仍禁止抓取。Answer 认证、写权限、内容和资金边界不变。
- 增加实际目录请求遵循 robots 规则的回归，以及公开 sitemap 页面、标签视图、私人页面和 JSON 响应的网关检查；同步搜索收录说明、架构与能力地图。

## 验证与升级

本地已通过社区测试（8 项 Python、137 项前端、6 项外观、27 项插件 JavaScript）、博客与前端构建、隔离 Nginx 配置与 SEO 检查、10 项发布回归。新增抓取回归在旧规则下复现失败，在修复后通过。完整 CI 与发布附件由现有 Release 工作流构建和校验。

已有服务器使用 `metar update --release v0.2.67` 升级，沿用完整备份、构建、健康及版本检查，无新增数据库迁移或运行配置。部署后对两个目录执行 Search Console 实时测试，核对渲染正文、robots 和资源加载；账户资源被 robots 阻止仍属预期。可索引或提交成功不等于已经收录，五个有意排除的报告 URL 应继续保持 noindex。
