# Meta Pulse v0.2.111

- 用户管理新增抽奖券剩余量、抽奖券总量、发帖数、发帖获赞数、评论数、点赞数、帖子被分享数七列，支持现有列设置隐藏与显示。
- 抽奖券总量含已用和过期券；评论数含回答与楼内评论；点赞数为主动点赞。社区与券统计独立降级，读取失败显示「—」。
- 分享数统计本版本部署后的主帖分享按钮点击，支持匿名与重复点击，不代表外部转发成功，不补造历史、不发权益。
- 需更新 Pulse API 与论坛镜像；论坛插件启动迁移创建分享计数表，浏览与本地登录不依赖统计接口。
- 验证：Go 测试/vet、路由 race、独立 MySQL 计数、Answer 补丁及正式 UI 构建、隔离源码社区前端检查通过。本地完整论坛镜像构建因 Docker Hub 503 未完成。
