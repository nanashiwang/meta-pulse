# Meta Pulse v0.2.102

## 修复云端 Blog 构建

- CI 不再对没有 pnpm 锁文件的博客目录执行动态依赖解析，改用仓库现有 `package-lock.json` 执行 `npm ci --ignore-scripts`，与本地构建保持一致。
- 修复此前云端解析出 registry 不存在的 `@algolia/ingestion@1.63.0`，导致 Release Blog job 在依赖安装阶段失败的问题。

## 管理员绑定查询校验

- 请求体严格限定为单个完整 JSON 对象，拒绝尾随字符、额外括号及超限请求体。
- 无数据库迁移。发布不等于生产部署。
