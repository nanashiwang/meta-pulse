Meta Pulse 首个独立版本发布。

- 新增版本标签触发的 Release 流程：完整 CI 通过后构建附件，先上传草稿并重新下载校验，最后正式发布。
- 提供 Linux AMD64 / ARM64 程序包（API、Worker、运维工具）、METAR 与博客静态资源、源码包、SHA-256 校验文件及版本清单。
- 支持 `metar update --release v0.1.0`：核对已发布版本与提交、备份数据和私钥卷、构建全套服务、迁移并核验实际镜像版本。
- 纳入 METAR 管理员网页配置、独立角色密钥、运行配置持久化，以及摘要最近 100 条流水和账本对账性能修复。

已有部署的 `.env`、社区插件配置、数据库及 API/Worker 私钥卷保持原样。新版本不会自动启用抽奖或发奖；正式开放仍需完成奖池、预算与 new-api 限额配置。

升级说明见仓库 `docs/RELEASE.md`。二进制包面向自行管理服务的 Linux 运维；现有 Docker 部署请使用指定版本升级命令。容器由版本源码构建，本版不发布公共容器镜像。
