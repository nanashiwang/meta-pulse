# Meta Pulse v0.2.36

修复从帖子返回讨论列表时先出现“最新讨论”标题占位、再重新生成页面的闪屏，并统一相邻入口的加载体验。

## 改进

- 首页、讨论、标签、知识库及通用入口直接输出包含页头、侧栏、主内容和手机导航的完整匿名骨架，主脚本延迟时仍有清晰页面结构。
- 首屏和站内切页共用列表、网格与面板骨架；适配中英文、深浅主题和窄屏。
- 浏览器恢复同一公开页面时保留已显示内容、滚动位置和搜索草稿，后台更新；失败明确提示并支持重试。
- 主脚本失败或长时间未完成时提供重新加载和原生社区入口，保留无 JavaScript 的公开内容回退。

## 边界与升级

个人、管理员、账号绑定、Pulse 权益与服务状态仍实时加载；身份变化后不复用旧会话内容。不持久保存页面快照或业务数据，不改动论坛写操作、身份、账本、预算或发奖流程。

沿用现有 Python 社区构建与版本升级流程，无新增迁移。发布不自动部署生产；服务器升级到本版本后才会使用新骨架。
