# Meta Pulse v0.2.14

- 新增独立社区经验体系：累计门槛为 0、150、600、1,750、4,500、10,000、22,500、45,000、90,000 EXP，不按月清零。
- 新增签到、连续七天签到奖励、问题/回答/点赞/采纳经验、精选和人工调整；内容与互动观察 24 小时，来源失效会追加撤销记录，重复操作不能刷取经验。
- 个人空间加入成长卡；社区成长页提供升级进度、通知、等级装扮、规则与经验明细。公开作者展示等级；管理员可配置规则、评选精选和审计调整。
- 使用 Answer 本地身份与插件独立 MySQL 账本，未绑定 API 的用户也可参与；EXP 不转换为额度、贡献值或券，不改变社区治理权限。
- 增加真实 MySQL 100 次并发签到、奖励重放、每日限额、撤销、规则冻结、权限与历史防篡改回归。已验证本地 Answer 登录、签到刷新、升级解锁和 390 像素深色页面。

升级需要重建 Answer 插件并更新社区静态资源、Nginx。插件使用已有 `FORUM_BINDING_GUARD_DSN` 初始化 `metar_exp_*` 表及防篡改触发器，数据库账号须有建表/触发器权限。首次初始化之前的内容不自动补发经验；请先备份 Answer 数据库。

此版本包含可信脉冲经验入账基础，但不自动增加经验奖项或修改既有活动。完整奖池类型与交付链路另行发布；发布不代表已部署线上。
