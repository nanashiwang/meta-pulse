# v0.2.11

为 metar.uk 增加自有前置反代配置，支持 Cloudflare 仅 DNS 指向前置机，再通过校验证书的 HTTPS 连接业务服务器，便于处理搜索验证节点直连源站异常。

- 源站只信任前置机精确 IP 提供的真实访客地址，重新生成可信转发链，保留访客限流与原有 Answer 认证、Cookie 和 Pulse 权限边界。
- 前置机不缓存页面/API，保留 noindex/no-store，访问日志不记录敏感查询串。
- 两台服务器分别持有证书，前置机的 ACME 文件缺失时转发源站，兼容双方自动续期。
- 新增双 Nginx 集成回归，覆盖伪造 IP、认证/Cookie、跳转、双端 ACME 及不可信回源证书拒绝。

配置与 DNS 切换需要独立部署验收；版本发布不代表百度验证或收录已通过。发布复用完整 CI 与附件下载校验。
