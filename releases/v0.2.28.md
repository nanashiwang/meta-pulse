# Meta Pulse v0.2.28

- 公开讨论、标签、搜索与知识库不再等待身份接口返回后才加载。个人、绑定、Pulse 和管理页仍等待真实身份确认，身份服务故障不阻塞公开浏览。
- 站内切页保留页头、导航与未提交的搜索内容，身份更新和内容加载不打断正在输入的搜索。浏览器前进后退恢复列表位置，迟到的旧请求不覆盖新页面或重置滚动。
- 成长与管理模块改为按需加载，作者等级在内容显示后增强。公开列表、标签和搜索采用短期内存复用与并发合并，按身份令牌与语言隔离，重试和身份变化清理；个人、权益、结算、权限与后台数据仍实时读取。
- METAR 静态资源与公开知识库启用 gzip，保留资源更新验证；头像延后加载，加载中显示稳定骨架。修复 320px 页头账户入口被挤出的情况，并在窄屏自动露出当前话题筛选。
- 补充公开与身份并行、受保护页面等待、缓存隔离与失效、历史位置恢复、重复导航、按需构建及真实 Nginx 压缩与条件请求回归，并完成浏览器交互验收。

本次不新增数据库迁移。附件包含 Linux amd64、Linux arm64、web、source、release-manifest.json 与 SHA256SUMS，全部校验后公开。

发布不代表生产服务器已部署。性能对比来自固定延迟的本地验收；生产速度需在部署后实测。
