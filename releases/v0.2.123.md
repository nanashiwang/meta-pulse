# Meta Pulse v0.2.123

- 每日签到统一放到“签到抽奖”页面，社区成长页及个人空间移除签到按钮，等级、经验与明细保留。
- 签到后自动查询赠券进度，到账后自动更新抽奖券数及单抽、五连抽按钮，不再需要刷新浏览器。
- 网络失败、响应丢失及后台延迟时有界重试，超时可在页面内继续查询；离开页面或切换身份后旧响应不会更新页面。
- 未绑定账号在统一入口仍可签到领取经验，不调用 Pulse；绑定前签到不补发券。签到日上限、发券幂等及账本规则不变。
- 本版本未新增签到人机验证；现有每日一次规则不等于阻止自动签到机器人。签到界面改动更新社区静态资源后生效。

本次版本同时包含 main 已有的未发布更新：帖子作者与采纳标签修复、评论/回答入口区分、待回答与精选侧栏、布局和固定页脚修复、管理员内容运营及返回导航改善。迁移 00021 为历史券统计建立展示基线，保留原始流水、可用券和到账奖励；完整升级须配套更新 Pulse、Forum、静态资源和网关，并按现有流程执行迁移。详见 CHANGELOG.md。
