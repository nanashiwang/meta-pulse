# Meta Pulse v0.2.59

## 更新内容

- 左栏上方增加「我的草稿」「我的消息」「近期活动」，同步手机抽屉与原生通知导航。
- 草稿列表接通 Answer 原生编辑器，支持多份本机草稿、继续编辑、删除和发布后清理；按稳定账号 ID 隔离，旧版草稿需确认归属后导入。草稿仅保存在当前浏览器，最多 30 份，不支持跨设备同步。
- 我的消息复用既有私聊、群聊和未读状态，增加通知中心入口。
- 管理员可发布、编辑、取消免费社区活动并查看报名名单；成员可报名或取消报名，公开页面只展示人数。并发报名不能突破人数上限，重复请求安全恢复。
- 活动不产生 Pulse 券、贡献值或自动奖励；升级不会自动发布活动或替用户报名。

## 验证与升级

前端、插件 Go 测试及 vet、真实 MySQL 并发重放/权限回归、论坛镜像构建、网关与浏览器流程验收通过。使用 `metar update --release v0.2.59` 完整升级；新增表在 Answer 数据库中由插件初始化，继续纳入现有备份。
