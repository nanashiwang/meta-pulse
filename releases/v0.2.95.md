# Meta Pulse v0.2.95

## 自建 DNS 递归出口探测

- 网络检测页面新增实际 DNS 探测流程：随机域名触发递归查询，同源 API 返回权威端观测到的 DNS IP，不再只有静态不可用占位。
- 独立无数据库 dnsprobe 服务支持 UDP/TCP 权威 DNS；不做递归、不采集账号，查询名与回读凭据独立，结果最长 90 秒后清理。
- 展示等待、查询结果、超时与服务未启用状态；不把没有结果解释为安全，不伪造 IP 地区。
- 新增默认关闭的 Compose profile、精确端口绑定、同源 Nginx 限流与凭据隔离；沿用安装/更新脚本，探测失败不影响论坛或 Pulse。
- 首次启用需要 `dnsprobe.metarhub.com` NS 委派、源站 UDP/TCP 53 和 `.env` 开关。详见 `docs/DNS_PROBE.md`。仅发布版本不会自动修改 DNS 或部署生产。
