# Meta Pulse v0.2.29

## 使用体验

- “跳过动画”改为抽奖面板左下角的复选框，记住浏览器选择；勾选立即跳过当前演出，后续直接展示服务端结果。
- 慢网络下晶体保持轻量呼吸和粒子环绕，避免蓄能阶段静止；保留系统减少动态效果、后台暂停及两种光效。
- 中奖后先展示奖项，奖励在后台发放；状态有界自动刷新，发放中可继续浏览或在资格确认后再次开启。
- 社区经验领取与 ACK 移出中奖/奖励历史 HTTP 响应，改为有并发上限、同用户合并和有限重试的后台任务，离开页面不会取消。

## 一致性与恢复

- 保留绑定实时复核、原 Grant/ACK 幂等、撤销保护、额度 Worker 和所有经济规则。
- 后台唤醒队列不替代持久化 Outbox；队列满、进程退出或重试耗尽后，未完成任务仍由后续奖励记录/成长页访问触发恢复。
- 跳过、查询状态和页面切换不会新增抽奖；未知结果继续使用原操作编号恢复。

## 升级

本次包含正式前端和 Answer 插件更新，需要同时更新静态资源并重建论坛镜像，不能只更新前端或使用 `--skip-forum`。无数据库迁移，不修改现有奖池、概率、发奖开关或密钥。

GitHub Release 发布不等于生产部署；实际到账与线上版本仍需部署后核验。
