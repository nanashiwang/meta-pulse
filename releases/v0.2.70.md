# Meta Pulse v0.2.70

- 发帖、回答与编辑正文时自动识别外链图片，下载后经 Answer 原生上传保存，成功才替换正文，无需逐张另存再上传。
- 支持 Markdown 与原生富文本粘贴、导入进度、失败保留原图和重试；同一来源合并，同页多个编辑器顺序处理。
- 保留普通链接、代码示例、图片说明及正在编辑的文字；删图、切页和切换账号不被迟到结果覆盖，导入期间等待完成后再提交。
- 下载仅允许活跃社区账号、同源请求和公开 HTTPS 光栅图片，校验 DNS/重定向并限制大小、像素、超时及频率。
- 复用现有 Answer 上传、Storage、文件记录与备份，不增加 Pulse/new-api 依赖，不自动重写历史帖子。

支持 PNG/JPEG/GIF/WebP，单张下载上限 5 MiB，上传仍受本站更严格的设置约束。来源失效、网络限制或超限时保留外链并提示重试，必要时仍需手动上传。升级需重建 Forum；本次 GitHub Release 不代表生产环境已经更新。
