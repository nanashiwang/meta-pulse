# v0.2.12

统一通知页与社区的导航体验，修复后台返回网站时的重复页面切换。

- 通知与成就页面使用 METAR 社区分组侧栏，支持桌面、手机抽屉、中英文与深色主题，并高亮通知中心。
- 保留 Answer 原生通知筛选、分页、已读操作；管理与审核入口跟随 Answer 自身权限，不修改身份或通知数据边界。
- 站点 Logo 和后台“返回网站”直接打开 `/latest`，避免先渲染 Answer 旧首页再完整跳转；保留浏览器离页提醒及原生编辑器草稿保护。
- 其他原生路由继续使用现有导航桥与路由守卫。

需更新包含插件的 forum 镜像（不要使用 `--skip-forum`）。发布成功不代表生产已部署。

富文本编辑器/多行编辑表单中的站名点击保留原生 React 路由确认；用户确认后才由既有导航桥交接。直接首页导航仅用于非编辑页面。
