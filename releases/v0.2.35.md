# Meta Pulse v0.2.35

完善单机部署下的基础设施可迁移性与恢复工具。默认继续使用本地 MySQL 8.0、Redis 和原数据卷。

## 改进

- Pulse 数据库、Forum 数据库与 Redis 可分别配置本地或外部模式，安装和更新统一预检，外部模式不要求本地 root 凭据。
- 增加 Redis URL、ACL 与 TLS，完善 MySQL 超时、连接池和 CA；拒绝不验证证书或自动降级的 TLS 模式。
- Forum 启动前核对 Answer 与插件连接，显式同步工具仅修改数据库字段并保护原配置。
- 更新备份补齐 Answer 配置与附件；新增完整恢复集、清单校验、失败保护和保留策略。
- 支持 restic 加密备份、实际回读校验和显式安装定时器，提供无网络 MySQL 恢复及本地账实核对。
- CI 增加 MySQL 8.0/8.4 回归，以及真实 Docker 跨版本恢复和加密回读演练。

## 运维说明

外部模式须使用部署助手或 `bash deploy/compose.sh`，需要 Compose 2.20+。步骤、权限、维护窗口和恢复限制见 [基础设施指南](../docs/INFRASTRUCTURE.md)。

本版本不自动升级生产数据库、不迁移生产数据、不启用异地任务；当前没有真实异地目的地。合成演练不能代替生产历史数据、完整 Answer 页面、密钥解密和 new-api Benefit 对账验收。每天全量备份不代表分钟级恢复能力。
