修复正式版本升级后的社区静态页面访问问题。

- 博客构建会替换静态目录；升级脚本现在同步重建 Nginx 网关，刷新 Docker 目录挂载，避免首页和博客持续返回 404。
- 增加指定版本部署的网关重建回归，覆盖 Nginx 配置文件没有修改的场景。
- 公开静态资源显式使用目录 755 / 文件 644，避免部署进程的私有 umask 阻止 Nginx 读取；验收增加 Nginx 用户读取检查。
- 保留 v0.1.0 的独立 Release 流程、双架构程序包、完整附件校验与运行版本验证。

v0.1.0 的升级脚本自身需要这项修复，请先在干净的部署仓库取得新脚本，再执行完整升级：

```bash
cd /opt/meta-pulse
git fetch origin refs/tags/v0.1.1:refs/tags/v0.1.1
git merge --ff-only v0.1.1
metar update --release v0.1.1
```

后续使用 `metar update --release 版本号` 即可。本次不修改数据库模型、运行配置、密钥、限额、影子模式或发奖开关。
