# Meta Pulse v0.2.0

社区首页改为紧凑话题列表，页面地址不再需要 `#`。

- 首页与 `/latest` 展示标题、标签、参与者、回复数、浏览量和活动时间，移除介绍统计卡及右侧推荐卡。
- 保留活跃、最新、热门、高赞、待回答筛选和分页；修复原列表缺失布局样式。
- `/topics`、`/question/:id`、`/admin/pulse` 等普通路径支持直接访问、刷新和浏览器前进后退；已有 `/#/...` 分享链接自动转换。
- 收藏与通知壳层使用 `/me/bookmarks`、`/me/notifications`，与 Answer 原生发帖、账号、通知及 SSO 路径分别处理。
- 完善手机、深色和中英文显示；讨论数据继续来自 Answer，奖励与配置保持原值。

## 升级

执行 `metar update --release v0.2.0`。必须同时部署静态资源与 Nginx 路由配置；完整发布流程会完成这两项。无新增数据库迁移，不开启自动发奖、不修改限额或密钥。

## 验证

前端构建、适配器/语言/History 路由回归、网关路径边界及 Nginx 配置检查；真实浏览器验证旧链接、筛选、详情、刷新、前进后退、手机和深色模式。Release 仍以完整 CI 和六个发布附件校验为门禁。
