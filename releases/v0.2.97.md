# Meta Pulse v0.2.97

## 社区注册人机验证

- 新增 Cloudflare Turnstile 验证码插件并编入论坛镜像，复用 Answer 原生注册表单和服务端校验。
- 启用后注册必须通过服务端验证；拒绝缺失、伪造、过期或重复令牌，以及域名和用途不匹配的结果。验证服务超时或异常时拒绝操作。
- 支持验证失败重试、取消和令牌清理，保留原生登录阈值与邮箱流程。
- 增加验证失败关闭、配置并发、前端生命周期和 Answer 原生策略回归。

## 部署要求

部署新版 forum 后，管理员须在 Answer 插件后台配置真实 Site Key、Secret Key、允许域名并启用 Cloudflare Turnstile。发布本版本不会自动为生产站点开启验证；密钥不能提交仓库。操作步骤见 services/forum-plugin/captcha-turnstile/README.md。
