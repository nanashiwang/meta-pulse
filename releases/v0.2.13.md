# Meta Pulse v0.2.13

- Pulse 管理页新增「设置兑换比例」按钮，支持用直观单位配置 API 贡献倍率与每张脉冲券所需贡献度，并创建完整的 10 天奖池周期。
- 展示已有周期的只读比例，新周期启用后冻结经济规则；保存不会自动开启抽奖、发奖或更改既有账本。
- 补齐管理员认证 BFF、同源校验、整数精度校验、事务幂等与审计；响应丢失可在刷新后重试原请求，不重复创建。
- CLI 与网页统一串行检查周期时间，拒绝并发创建重叠周期；新增 MySQL 并发、权限与前端恢复回归。

升级需更新 Pulse API、Answer 插件与社区静态资源及 Nginx；无需新增数据库迁移。已有周期、配置与密钥保持不变。发布不代表已升级生产服务器或开放真实发奖。
