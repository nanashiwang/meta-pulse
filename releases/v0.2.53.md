# Meta Pulse v0.2.53

社区新增私聊和群组交流，顶部重复的“发布”按钮改为“聊天”，话题列表保留“新建话题”。

## 群组生命周期修正

- 解散群组时，同一事务取消待确认邀请，不再隐形占用受邀者的会话名额；旧数据中的已解散群邀请也不计入名额。
- 已解散群组的成员和原群主均可主动退出。确认提示说明退出后无法再次查看历史；其他尚未退出成员仍可阅读。
- 退出后清理当前会话草稿与 URL，显示选择其他会话的提示，避免刷新回到已失去权限的群组。
- 新增 MySQL 群组关闭、退出和遗留邀请容量回归，以及群主/普通成员关闭状态的界面权限回归。

## 聊天功能

- 使用 Answer 已激活的社区账号发起一对一文字私聊、创建群组，无需绑定 API 账号；同一对成员始终复用会话。
- 群组最多 50 人，邀请需要确认；群主可改名、邀请和移出成员、转让或解散，普通成员可以退出。新加入及重新加入的成员只能看到加入后的消息。
- 会话列表、未读提示、历史分页、增量更新、内存草稿与原请求重试；手机双视图和中英文、深浅主题适配。
- 两分钟内撤回自己的消息、屏蔽成员、举报单条消息。管理员只审核被举报消息快照，处理说明、操作者及时间保留审计。
- 独立 MySQL 事务保存消息和幂等回执，实时校验账号及成员权限；聊天接口不缓存，页面不进入搜索收录。

## 验证

真实 MySQL 事务测试覆盖 100 次并发同请求只保存一条消息、双方同时发起私聊、成员移出与重新加入、历史/变化分页、撤回旧消息、未读游标、封禁及管理员降权、屏蔽与限额。CI 同步加入 MySQL 8.0/8.4 聊天回归。

本地编译的 Answer 与 MySQL 使用三名测试账号，完成私聊、群邀请确认、普通成员权限、未读、草稿、举报处理和发送响应丢失后的重试验收。检查桌面与 320px/390px 手机布局、中英文和深浅主题，配合现有前端、Go、部署配置、构建和笔记门禁。

## 部署与范围

需要同步升级论坛插件、METAR 静态资源与网关路由。首次聊天请求通过已有 `FORUM_BINDING_GUARD_DSN` 创建 Answer 库内 `metar_chat_*` 表，需要建表权限；现有 Answer 备份包含消息数据。聊天初始化失败不影响社区登录、浏览及 Pulse 主链路。

本版为文字聊天，暂不包含附件、音视频、在线状态或浏览器推送。消息按成员权限保护，并非端到端加密；历史、幂等回执和举报审计默认保留，不自动删除，容量需随 Answer 数据库监控。详细限额见 [社区文档](../docs/COMMUNITY.md)。

GitHub Release 不自动部署生产服务器。
