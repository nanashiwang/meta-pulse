# Meta Pulse v0.2.33

## 跳过蓄能，保留闪光与翻牌

- 修正勾选跳过后整段演出消失的问题：左下角选项更名为“跳过蓄能”，只省略微光汇聚和晶体蓄能。
- 收到真实奖励后仍播放约 2.1 秒的外放光晕、卡片光幕、轮廓浮现和翻牌揭晓；单抽与五连抽均保留各自档位的光效。
- 已保存的跳过偏好继续生效。演出中途勾选只向前推进，揭晓时重复操作不会倒退或重新闪光；取消勾选对下一次开启生效。
- 系统减少动态效果、页面隐藏和无 Canvas 环境继续直接显示已确认结果，采用独立的无动画分支。

- 回归覆盖完整与短演出时序、五张卡的闪光、中途切换、无动画优先级，以及单抽/五连抽、响应丢失恢复、中英文和手机布局。
- 实际浏览器使用本地模拟奖励并采用线上相同的安全响应头验收，未消耗真实脉冲券。版本发布与线上升级分开核验。
