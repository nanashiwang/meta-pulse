# Meta Pulse v0.2.16

本版本完成社区经验与脉冲奖项的连接，包含 v0.2.15 的完整成长体系。累计等级门槛按原方案五倍设置：0 / 150 / 600 / 1,750 / 4,500 / 10,000 / 22,500 / 45,000 / 90,000 EXP。

- 创建新周期时可选择 API 额度或社区经验奖项，分别设置 quota 与 EXP 预算；经验不兑换贡献值、脉冲券或余额，不授予管理权限。
- 经验奖项经受保护的社区绑定和独立 BFF 签名领取，先提交 Answer 经验账本再确认 Pulse；断网、响应丢失和重复领取不会多发，积压奖励不受最近 20 条历史窗口限制。
- 成长管理新增脉冲经验来源撤销；经验与 API 额度的交付队列、预算和撤销路径隔离。Shadow Mode 不实际发放经验，已有周期和概率保持冻结。
- 成长页、个人页与 Pulse 操作触发有界同步；网络故障提示稍后刷新，签到与社区内容经验继续独立可用。离线账号的经验到账或扣回在下次访问时完成。
- 补齐混合预算、100 次并发抽奖/到账确认/撤销、伪造身份拒绝、跨服务确认失败恢复、金额冲突及迟到消息防复活测试。

升级需更新 Pulse API/Worker、Answer 插件、METAR 静态资源和配套网关配置。Pulse 无新增数据库迁移；社区经验首次初始化需要 Answer 数据库 CREATE TABLE / CREATE TRIGGER 权限，备份包含 `metar_exp_*` 表。启用经验奖池后，不可单独回退至不支持经验类型的旧服务版本。

本次发布不自动部署生产、不修改已有活动、不打开真实发奖开关。规则、恢复与对账方法见 [社区经验说明](../docs/COMMUNITY_EXPERIENCE.md)。
