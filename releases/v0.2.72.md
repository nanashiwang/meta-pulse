# Meta Pulse v0.2.72

- 修复帖子详情、标签、登录和用户等原生论坛页面在未配置品牌图标时显示 Apache Answer 默认蓝色图标的问题。
- 复用首页现有 METAR 绿色标识，提供 16、32、48、64、128、256 像素的真实 ICO，由网关统一处理 `/favicon.ico`，覆盖原生首屏、前端导航和默认 manifest。
- 知识库页面显式使用 METAR SVG 图标，保持跨入口一致。
- 图标资源使用重新验证缓存策略；保留 Answer 管理员已指定的其他图标 URL，不修改帖子、账号或站点数据库配置。
- 真实 Nginx 检查覆盖图标文件、响应类型、安全头、缓存和博客 HTML；导出方法随前端文档维护。

升级需同时更新静态资源和网关。浏览器可能保留旧 favicon 缓存，部署后需重新打开标签验证。发布完成不代表生产部署已完成。
