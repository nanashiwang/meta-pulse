# Meta Pulse v0.2.64

## 更新内容

- 参考礼盒与晶石视觉重做 Pulse 主舞台，采用按需加载的 48 KB WebP 背景，放大奖励卡片与单抽、五连抽按钮，支持浅色、深色和窄屏。
- 右上角脉冲券入口展示真实可用数量并打开权益详情，保留抽取规则、跳过蓄能和刷新入口。
- 下方展示本人的最近五条奖励与权益概览；完整记录、到账状态和奖励编号继续在原生弹窗中查看。
- 记录刷新失败时保留已确认数据，资格刷新保持弹窗、焦点和揭晓结果。沿用原 Action 恢复、减少动画、无 Canvas 和脚本加载失败时的基础操作。

本次只调整展示，不修改奖励概率、预算、券消费或结算。经验与额度按实际 EXP / ⚡️ 单位展示；没有新增公开社区中奖动态或示例中奖记录。

## 验证与升级

前端 131 项、构建 8 项、壳层 6 项与插件 JS 27 项回归通过，博客及社区构建和决策笔记检查通过。真实浏览器以隔离合成数据验证中文浅色、中文/英文深色、320/390px 窄屏、单抽与五连抽、历史错误保留、中断恢复、弹窗焦点及降级显示，未消耗生产脉冲券。

使用 `metar update --release v0.2.64` 完整升级。
