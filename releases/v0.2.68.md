# Meta Pulse v0.2.68

## 更新内容

- METAR 源站配置迁至 NAN `104.168.114.150`，前置入口按实际部署同步为 `155.103.118.155`。同时更新固定 HTTPS 回源、HTTP ACME fallback 和源站精确可信代理地址，保留回源证书验证、Cookie、认证与限流边界。
- 更新双 Nginx 回归中的真实可信代理地址，继续覆盖伪造转发头、认证透传、私有页面缓存与索引限制、两端证书挑战路径和错误证书拒绝。
- 补充整机迁移操作约束、逐表数据与触发器核对、完整恢复材料、单一 Worker 和 WireGuard 身份切换、禁止新库写入后直接回切旧库；同步能力地图及现场决策记录。

## 验证与升级

部署脚本离线回归、真实双 Nginx 测试和网关配置检查通过。完整 CI、跨平台二进制、源码和静态附件由既有 Release 工作流构建及回读校验。

没有新增数据库迁移，不调整绑定、业务密钥、经济规则、影子模式或奖励开关。仓库配置和 Release 本身不会迁移生产数据；已有部署须在完整备份后执行 `metar update --release v0.2.68`，前置机配置单独通过 `nginx -t` 后热加载。具体迁移结果与验收限制见决策笔记。
