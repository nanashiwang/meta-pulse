# Meta Pulse v0.2.126

## 社区内容运营定时讨论

- 内容运营支持 JSON 文件及粘贴导入，多运营账号发帖、定时回答、回答下评论和评论回复；同批 parent 引用免手工复制新帖子编号。
- 新增持久化批次队列，关闭页面或重启后继续；支持取消剩余内容、原请求核对继续及稳定批次编号防重复提交。
- 继续使用 Answer 原生内容权限与审核、专用账号登记和公开运营代发标识；每项执行复查管理员和目标资格。
- 提供可修改 JSON 示例及操作文档。升级需配套重建 forum 与社区静态资源；新增批次表随 Answer 数据库备份。
