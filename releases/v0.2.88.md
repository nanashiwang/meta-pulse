# Meta Pulse v0.2.88

## API 消费贡献退役

- API 消费、退款和补录不再进入 Pulse，不新增用量、付费证明、贡献账本/快照，不再推进消费游标。
- Worker 不再连接 new-api LOG_DB；旧日志库、消费批量、消费水位和贡献周期奖励环境配置不能重新开启该功能。结算、查询对账、旧周期关闭、内容采集和账本/预算监控继续运行。
- 补录、回测、游标移动和摄入验收命令在访问数据库前明确拒绝。旧算法仅作为历史账本回归测试夹具保留，不编译进生产进程。
- 用户概览及社区资料不再展示 API 消费贡献与等级，管理页不再提供贡献倍率。兼容接口返回零贡献、retired 等级，以及 api_usage_enabled=false / contribution_status=retired；历史数据未清零。
- 内容奖励取消付费贡献资格，仍保留保护绑定、人工审核、独立预算和限额。旧周期关闭不等待消费水位，也不创建新的贡献型周期奖励。

## 保留与升级

社区签到/互动赠券、Answer EXP 成长、已有券、抽奖、额度与经验奖励交付、已生成奖励的查询/结算/撤销均保留。历史 Ledger、Usage、规则快照及 Grant/Outbox 不删改，无数据库破坏性迁移。

同时升级 API、Worker、离线工具与 forum（勿用 --skip-worker 或 --skip-forum），并从升级脚本调用方移除 --accept-ingest。确认全部旧进程停止、新 Worker 健康后，再回收 Meta API 中仅供 Pulse 的日志只读账号；不要先断权限或停整个 Worker。回滚旧版会恢复消费摄入。

Meta API 的入口与配套代码需独立更新，Benefit 和身份绑定接口继续保留。发布附件不自动部署生产，实际社区任务领取、抽奖及真实到账须在部署后验收。
