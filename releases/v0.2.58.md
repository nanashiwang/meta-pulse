# Meta Pulse v0.2.58

## 更新内容

- 修复恢复演练的间歇失败：等待 MySQL 正式实例通过容器内 TCP 认证查询，再执行建库、导入和对账，避免连接到即将关闭的初始化临时实例。
- 就绪探测增加整体截止时间和单次超时；恢复 SQL 失败不自动重放，继续清理隔离容器。
- 报错保留失败阶段、退出码和 MySQL 数字错误码，隐藏原始 SQL、凭据与数据库内容。
- 补充临时实例、超时清理、诊断脱敏及真实延迟初始化回归，保留本地/外部备份、账实核对和 restic 加密回读验证。

## 升级

使用 `metar update --release v0.2.58`。本版发布不自动部署生产，也不变更现有数据库或备份。
