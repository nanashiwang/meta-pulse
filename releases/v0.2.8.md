# v0.2.8

修复 Google 真实渲染首页时的抓取阻断：公开帖子查询此前被 `/answer/api` 的 robots 规则挡住，前端加载失败后会输出 noindex，导致首页索引请求被拒绝。

- 为公开问题列表、问题详情、回答列表和标签列表添加精确的 robots Allow 规则，包含无参数和查询参数地址。
- JSON 接口继续返回 noindex，账户、通知、管理与权益 API 仍受抓取限制，访问权限和认证规则不变。
- 保留 Google、百度验证标签、站点地图及 v0.2.7 的升级期间静态目录保留修复。

验证：公开渲染资源和私人接口的 robots 规则回归、社区测试与构建、Nginx 收录检查；正式发布使用完整 CI 及附件校验。
