# Meta Pulse v0.2.2

本版改善 metar.uk 的搜索引擎抓取：公开入口在初始 HTML 中包含说明和链接，新增入口站点地图，并修复知识库 sitemap 缺少 /blog/ 前缀的问题。

- 保留 Answer 原生帖子正文、QAPage 和动态 sitemap，壳层详情指向原生规范地址。
- 页面导航同步标题、描述、canonical 与 robots；个人、通知、账号绑定、管理、搜索和奖励入口禁止收录。
- 博客不存在的地址返回 404，构建目录不再形成重复公开入口。
- 准备 Google 站点验证标签，补充 Google、百度、Bing 平台提交与上线核验说明。
- 新增真实 Nginx 抓取回归，验证爬虫内容一致、私有页面 noindex、站点地图目标和错误状态。

升级沿用 `metar update --release v0.2.2`。发布只交付网站能力；实际部署、站长验证、提交成功和搜索引擎收录是不同状态，需逐项验收。
