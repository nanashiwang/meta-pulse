# Meta Pulse v0.2.82

- 取消 Meta API 消费额度获得抽奖券的渠道，实时采集、重放与历史补录均不再发券；用量、付费证明和贡献统计继续记账。
- 保留社区获券：帖子每收到 10 次评论得 1 张、每天最多 2 张；给别人每点赞 40 次或评论 20 次各得 1 张，分别累计、两项合计每天最多 3 张；每日签到另得 1 张，每天合计最多 6 张。
- 已获得的抽奖券、原有效期及中奖结果保留；消费退款继续按原校验处理贡献，不自动增减券。
- 抽奖页移除消费获券与 0.2 元等价说明；管理页改为“设置奖励规则”，去掉每张券所需贡献度，API 贡献倍率仅用于贡献统计。
- 补充消费 100 次重放、跨规则不加券、补录及退款隔离回归，并验证旧券和社区券的正常抽奖、事务恢复与账本对账。

需同步升级所有 Pulse Worker、离线工具、Pulse API 与正式前端；社区任务继续使用 v0.2.81 引入的 Forum 采集能力。仅更新网页不能阻止旧 Worker 消费发券，回滚旧 Worker 会恢复该渠道。无新增数据库迁移，不清空历史账本或券。GitHub Release 与生产部署分别验收。
