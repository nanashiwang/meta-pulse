# Meta Pulse v0.2.63

## 更新内容

- 最新、热门、高赞、待回答、分页及类别/标签切换时保留当前列表，新数据成功后一次替换内容与筛选高亮，避免先清空再显示。
- 慢请求延迟显示轻量加载提示；失败保留旧列表并提供明确重试入口。
- 快速连续点击只提交最后一个目标，迟到响应不能覆盖当前选择；滚动位置在新列表就绪后处理，支持浏览器前进后退。
- 复用当前作用域的公开目录，减少筛选控件的中间占位。首次访问、其他页面类型及身份/语言变化沿用原加载和校验；权限拒绝清除旧视图。

## 验证与升级

前端与构建、网关回归通过。真实浏览器在隔离接口夹具中覆盖约 1.2 秒延迟、乱序响应、失败重试、空结果、分页/类别、历史滚动及 390px 英文深色；公开列表切换未观察到内容清空阶段。使用 `metar update --release v0.2.63` 完整升级。
