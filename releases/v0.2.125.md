# Meta Pulse v0.2.125

- 修复频繁部署后构建缓存持续堆积的运维缺口。`metar update` 即使提交相同，也在更新锁内回收本机默认 builder 的未使用缓存，保留目标 8 GB。
- 更新前、备份后的构建前检查仓库及 Docker/containerd 文件系统，至少保留 20 GiB 空闲；不足或维护失败明确返回失败，更新退出时再次维护缓存。
- 不删除镜像、容器、数据卷、数据库 binlog、用户上传或备份，不新增定时任务，不重启 Docker。生产已有五分钟更新检查自动复用；首次旧脚本升级后，下一次调用取得完整保护。
- 新增缓存容量、旧版 Buildx 兼容、清理失败、远程 Docker 拒绝、同提交维护及低磁盘阻止更新的回归。
- 同步发布 main 已验证的社区白底配色与 Pulse 限时入口优化，以及跨页面返回循环修复、按历史位置恢复来源。

缓存容量是回收目标，不能限制正在使用的缓存或单次构建峰值。首次安装及直接手动 Docker 构建不经过更新保护；详情见部署文档。无业务数据库迁移或经济规则修改。
