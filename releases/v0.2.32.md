# Meta Pulse v0.2.32

## 卡片光幕揭晓

- 根据出金演出的视觉参考，强化“蓄光 → 整卡光幕 → 晶体轮廓 → 奖励显现”的完整过程。强光阶段暂不显示奖励数值，待光幕消退再清晰揭晓。
- 金光与红光增加白热中心、扩散光晕、宽幅光束、光尘和镜头光线，缩短晶体碎片及光环的停留；浅色与深色页面分别调整环境压暗程度。
- 稀有奖励卡采用金属边框、角部高光、深色渐变卡面和持续余辉；白、蓝、紫三档保留逐级增强的光效。
- 五连抽逐张错峰揭晓，各卡按自己的档位发光；整体仍约 3.9 秒，桌面与手机面板保持紧凑布局。

## 体验与验证

- 保留左下角跳过动画、减少动态效果、无 Canvas 降级和后台发奖。未收到真实结果时不提前揭晓，不改变奖池概率、扣券、请求恢复或额度发放。
- 卡片位置与颜色只在结果、尺寸或主题变化时读取，逐帧演出使用缓存；演出结束后停止动画帧循环。
- 通过前端与社区回归、构建，以及真实浏览器中的五档结果、单抽与五连抽、浅色/深色、320px/390px、中英文、慢响应、跳过、低动态和无 Canvas 检查；同时复核响应丢失与部分完成后的原请求恢复。
