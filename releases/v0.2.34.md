# Meta Pulse v0.2.34

## 安全部署备份保留

- 更新脚本默认保留最近 3 份成功更新备份，支持 `--backup-keep N` 与 `META_PULSE_BACKUP_KEEP`；0 关闭清理。
- `--backup-preview` 只预览现有目录，不更新或删除。当前回滚基线、失败、中断、旧版未知状态与 `.keep` 备份始终保护。
- 全程复用更新锁，仅在健康检查、版本核验与所请求的摄入验收全部成功后清理。清理异常单独警告。
- 固定备份根目录，拒绝越界路径、符号链接、跨设备目录及不安全文件类型，删除使用 no-follow 目录描述符。

## 验证与升级边界

- 离线回归覆盖保留边界、预览、失败、TERM、并发互斥、链接替换和回滚点保护。
- 更新新增 Python 3 标准库依赖。旧脚本正在执行的更新不会自动获得新机制；后续执行新脚本才生效。无状态历史备份不自动删除，数量上限不包括受保护项。
- 本版只发布项目变更，未部署生产，也未删除生产备份。
