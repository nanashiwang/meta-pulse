# Meta Pulse v0.2.5

- 登录、注册、找回密码和发布旧入口直接打开统一主题的完整表单；保留参数，不等待身份接口恢复，也不允许配置导向外站或形成壳层循环。
- 私人空间增加公开主页、编辑资料和退出登录，侧栏补齐账号设置；真实激活管理员可直接进入社区管理、连接配置和 Pulse 配置。
- 清理普通用户流程中的“原始页面”等技术中转文案，统一页脚入口。
- 修复个人发布列表使用 `question_id` 时生成 undefined 链接的问题。
- 修复 Answer 1.7.1 UserCenter 注册守卫把本地注册导向插件接口的问题，仅修正本插件的前端注册目标，保留后端注册开关、验证码、邮件和权限检查。

- 将插件中英文语言资源纳入 Go vendoring，避免新部署显示翻译键名。

社区回归、插件 Go 测试、博客/社区与完整论坛镜像构建通过，并使用独立本地 Answer 验收。升级需更新 forum 与静态站点，并按现有备份/Answer 升级流程刷新既有数据卷的语言资源；生产邮件、验证码、附件和真实权限应在部署后继续验收。发布本身不代表生产已升级。
