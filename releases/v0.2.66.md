## 使用与验证

开发环境需要 Python 3.9+ 和 Bun（CI 使用 1.3.14）。克隆仓库后运行：

```sh
python3 .agents/workflow.py doctor
make verify-notes
python3 -m unittest discover -s .agents/tests -v
```

本地 `doctor`、23 篇笔记校验、6 项接入回归、10 项发布回归、`make test`、`make vet` 与 `make build` 均通过。重复安装预览无待写入项，文档中的 164 个本地链接均可解析。数据库和容器验收以 CI 实际结果为准，不将本地无 DSN 的跳过计为通过。

升级工具时使用完整的新安装包先预览，保留安装清单与项目自定义说明；无需重新创建 CI。详细步骤见 `docs/AGENT_NOTES.md`。

本次只调整开发工作流和文档，不修改业务 API、数据库模型、身份或奖励规则。安装校验不替代业务测试、真实账号或生产到账验收；本版本无需为启用开发工具而升级生产服务。
