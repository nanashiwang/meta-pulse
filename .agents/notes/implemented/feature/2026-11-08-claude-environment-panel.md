# Agent Note: Claude 访问环境检测面板

Status: implemented

## Problem

用户明确要求把简单网络自检扩展为 Claude 访问环境检测，包含截图中的评分、网络出口、六项信号和完整解释，原通用页面不满足该范围。

## Existing capabilities and impact

核对 FEATURE_MAP、app.js TOOLS、tools.js、共享路由与 nginx 出口接口。复用 /tools/network、工具下拉/手机侧栏、按需脚本、同源 IP 和 STUN 检测；不新增身份或后端服务。活跃笔记检索命中旧工具笔记：部分取代其“不评分/不采用 Claude 定位”的决定，导航及 nginx 边界仍成立，保留并互链；其他 DNS/迁移笔记无关。

## Decision

按用户给定六项权重 30/24/20/10/8/8 构建可解释本地估算，0.25 为命中阈值，0–30/31–60/61–100 分档；未知信号不假装为零风险，显示已测权重和部分结果。Canvas 字体宽度及 UA Emoji 风格是启发式，不代表国籍或账户风险。页面增加完整原理、FAQ、功能模块、Unicode 研究说明和防御建议；第三方逆向说法注明未独立验证，不承诺隐藏代理或不会封号。

页面在点击后直连固定 claude.com/claude.ai trace 端点，只有可读有效 IP 才展示；禁止使用服务端代理结果冒充访客分流出口。DNS 保留独立模块、未接入状态和说明，不能拿 DoH/网站 IP 冒充系统解析器。结果不持久化/上报，明确网络探测接收方会看到源 IP；保留失败、无候选和未知基准状态。首页与 History 路由 CSP 只额外允许两个固定 trace 路径，保持内联脚本/样式禁用；离开页面取消探测。中英文、深浅主题、窄屏均覆盖。

## Alternatives considered

- 保留旧三张卡：成本最低，但无法满足用户完整页面要求。
- 照搬参考站代码及结论：布局接近，但未知许可/版本和不可验证承诺不适合直接引入；重写 UI 和检测逻辑，保留来源链接。
- 后端代理 Claude/DNS 请求：能绕过 CORS，却测到服务器出口而非访客路由；专用 DNS 权威探针需要单独基础设施，不在本次伪造结果。

## Consequences

公开逆向分析可能随客户端版本变化，且评分容易被误读为身份或封禁判断；跨域探测受 CORS/网络限制，DNS 仍未实现。页面持续保留“未知”和非官方声明。

增加纯前端评分和内容维护成本；无法读取的跨域结果需用户自行打开检查。无经济链路或数据库变更。发布不等于部署。

## Testing

17 项 tools.test.js 测试覆盖评分边界、未知、语言/字体/UA、请求超时/格式/CORS、WebRTC 未知出口、导航销毁、重复扫描、转义和两处 CSP。make test-community、make build-community、笔记两种校验入口、nginx 容器语法/配置测试通过。

Playwright 本地壳层验收 1440px 桌面及 375px 手机、中英文、深浅主题、章节跳转、FAQ 展开与扫描完成；页面无横向溢出。网络实测 claude.ai trace 可读，claude.com 超时并显示未知。社区出口使用仅本地预览的文档测试 IP，因此 WebRTC 差异结果仅验证交互，不作真实泄露结论；预览未接 Answer，侧栏/身份接口错误符合预期。生产部署与真实用户验收未执行。
