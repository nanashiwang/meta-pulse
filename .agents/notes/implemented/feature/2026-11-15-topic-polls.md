# Agent Note: 帖子文字投票

Status: implemented

## Problem

用户授权实现第一版选项投票并提交，现有Answer赞同/反对票不能承载选项投票。

## Decision

插件复用Answer会话与帖子可见性，拥有metar_topic_poll、metar_topic_poll_ballot、metar_topic_poll_command三表，保存在论坛库、随现有论坛备份。每帖一投票，2—10项纯文本，最多选择1—选项数，1/3/7/30天。创建后题目/选项/限选/截止固定，作者可提前结束不能延长。每个账号一份选择，截止前用版本号替换；不得关联EXP、赞同票、券或闪电。

公开GET /metar/polls只返回公开帖子投票；登录GET /metar/polls/mine返回本人选择；POST /metar/polls/command接受create/vote/close。拒绝查询token、多余参数、重复JSON键、非同源写；用户ID只从Answer认证获取，数据库重查账号活跃/邮箱验证、帖子作者及当前可见性。投票写必须正常公开帖；关闭帖只读展示已结束，隐藏/删除/待审核帖不公开读取。作者可为自己的待审核新帖创建附属投票，仍不对外显示。

事务先共享锁用户、再锁帖子和投票，封盘/改票以锁后服务端时间为准。唯一账号+帖子约束、期望版本号和账号+请求键指纹防止重复计票/旧请求覆盖新选择。操作流水与选择同事务，超时重试相同键；返回只含成功回执，随后重新读取当前状态。读取共享锁帖子后以一致事务聚合，投票前不返回人数与counts；投后/结束后显示聚合，绝不返回选民名单。多选比例按人数计算，合计允许大于100%。

原生发帖通过小补丁在提交前校验投票，取得真实帖子ID后再附加投票；不重写Answer发帖事务。两次请求不是原子的：投票保存前保留账号隔离的恢复记录和原请求键，失败后在详情明确提示“帖子已发布，投票未确认”，只重试投票。站点存储不可用时阻止带投票发帖；提交后存储突然失效时保留当前页面内存恢复信息。作者也可在现有帖子正文下补建投票。标题选项使用textContent渲染，不解析HTML。私有恢复记录不包含凭据，不允许账号切换后提交给新账号。

## Alternatives considered

- 修改Answer发帖事务并合并写入：跨模块耦合更大；第一版选择有明确恢复入口的两阶段保存，代价是帖子可能暂时没有投票。
- 直接使用浏览器计票/已有赞同票：不能保证限选、改票、私密结果和并发一致性。
- 允许发布后编辑选项：可能改变选民原意；第一版保持不可编辑，需新投票时新发帖子。

## Verification

365项相关前端测试通过；插件和polls包Go测试/编译通过，本地未配置MySQL的集成用例跳过。新增CI MySQL8.0/8.4用例覆盖作者/用户状态、投前结果隐藏、16次并发同键重试、10次并发不同键旧版本、一人一票、改票、旧请求重放不覆盖新票、关闭与截止、隐藏和待审核帖子。实际Go module来源补丁零模糊校验通过；原生TSX按上游Prettier配置校验通过；资源闭包检查通过。浏览器模拟接口完整验证发帖附带投票、单选投票、投后统计、改票与提前关闭、375px布局和文字转义；未对生产用户发帖或投票。完整镜像与真实数据库检查以CI结果为准。

## Consequences

需重建forum，首次访问初始化三表；现有论坛账号/内容为权限事实源，新增投票不自动产生社区奖励。原生发帖和UI插件必须一起构建。旧普通帖子无投票保持原样，仅作者看到添加入口。截止时间按创建时起算，待审核耗时不自动顺延。关闭投票与请求指纹流水可审计，但没有管理员查看选民明细接口。
