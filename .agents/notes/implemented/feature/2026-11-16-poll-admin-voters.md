# Agent Note: 管理员查看投票明细

Status: implemented

## Problem

投票目前仅提供匿名汇总与本人选择，用户要求管理者能够查看参与者及所选项。

## Decision

保持普通成员、版主及非管理员作者不可查看他人选择。新增独立会话GET voters接口，数据库逐次校验正常/已验证账号及唯一角色关系为管理员2，拒绝降权和重复角色。不相信浏览器角色；前端角色仅决定按钮显示。沿用帖子公开可见性检查，不扩大隐藏帖访问权限。

按user_id稳定游标分页，每页50条，返回账号ID、用户名、显示名、当前选择和最后更新时间；读取历史已有记录，无需迁移，不提供改票轨迹。成功读取记录管理员、帖子和条数，不记录选票内容。私有响应no-store，前端不落盘，切换身份或角色时销毁面板，失败清除旧名单，迟到响应不能覆盖其他身份。

投票卡片对所有人明确提示个人选择不公开、管理员可查看。公开汇总及本人接口不包含他人票据。管理员入口位于原投票卡片，支持翻页、返回第一页和刷新。

## Alternatives considered

把投票者混入公开汇总响应再隐藏UI会泄露个人选择；给所有作者查看权限超出管理者需求；另造后台全站名单扩大数据暴露范围。因此选用独立授权接口与按帖子查看入口。

## Consequences

仅扩展社区投票读取，不改变票据、期限、奖励或汇总。角色查询每页重新执行，历史匿名措辞更新为对普通用户匿名、管理员可查看。需重建forum插件后才上线。
