# Agent Note: 左侧按需展开目录与 METAR 起步命名

Status: implemented

## Problem

用户明确上一版常驻侧栏长列表不符合预期，要求从左侧展开选项；直接沿用 Linux.do 的栏目名称也不符合社区定位。

## Decision

左侧只保留类别、标签两个入口，点击后在侧栏旁打开侧向选择面板；手机面板从左侧覆盖内容。复用原生 dialog 的焦点限制与 Escape，提供搜索、当前项高亮、完整目录链接和简洁申请入口。点击遮罩/关闭按钮可关闭；导航、身份和语言切换关闭旧面板。面板异步目录结果按会话与节点检查，不写入后来的面板。

起步名称改为 METAR 自身表达，保留 13 类别/7 标签的既有 slug 和语义。新初始化直接使用新名称；旧站由已激活管理员在类别管理中显式同步，先完成既有初始化与设置读回，再通过 Answer 原生标签编辑逐项更新仅与旧默认名称完全匹配的标签。读取并原样带回原文，保留 ID、slug、帖子关联、自定义名称及其他配置，并写入原生编辑摘要；读回验证后才报成功。升级或浏览页面不触发数据写入。

## Alternatives considered

- 默认折叠原有分组：改动最少，但仍把长列表插入侧栏，无法体现从左侧弹出选择内容的要求。
- 为名称增加前端显示别名：无需数据更新，但原生编辑器、搜索与推荐标签会继续显示旧名称，形成两个名称事实源。
- 更换 slug 并重建目录：命名彻底但破坏已有链接/标签关联；只更新默认显示名称，复用 Answer 原生审计。

## Verification

- 社区测试验证面板搜索、当前项、名称转义与完整目录入口；默认名称更新保持 ID、slug、原文、自定义名称和模拟帖子计数；重复同步零写入、丢响应重读、权限及不完整/不兼容标签响应、读回漂移均有回归。
- 隔离的 Answer 1.7.1 实例使用真实管理员会话创建旧起步标签，执行正式同步函数；验证新名称、原文与标识保留、推荐标签自动返回新名称、自定义名称保留，重复同步零写入。
- 正式构建搭配模拟内容验收桌面/320px/390px、中英文、深浅主题：默认无长列表、点击展开、搜索/无匹配、当前项、选择关闭、完整目录入口、Esc/遮罩关闭、焦点恢复与限制。故障时讨论保留，面板重试恢复并保留正确展开状态。
- 本地社区回归、社区/博客构建及笔记校验通过；本次未部署生产，也未写入生产标签。

## Consequences

侧栏保持紧凑，目录通过按需面板展开，增加一次点击但不长期占据侧栏。标签面板只筛选已加载的热门/起步标签，更多标签通过完整目录分页查看。名称由 Answer 统一提供，没有前端别名；旧站须显式同步，未同步前仍返回旧数据。原生标签编辑没有 CAS，管理员同步期间须避免其他人同时编辑标签与撰写设置；原文回传和读回验证能发现部分冲突，不能提供原子并发保护。未知写入结果保留当前状态，重试先读而不是盲目重发。
