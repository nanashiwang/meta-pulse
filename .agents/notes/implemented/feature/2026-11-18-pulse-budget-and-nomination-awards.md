# Agent Note: 签到券预算与优秀帖子推荐奖励

Status: implemented

## Problem

互动券使 300 人满额预算超过四周三万闪，推荐优质内容也缺少可查看和发放的奖励记录。

## Existing capabilities and impact

签到赠券复用 Answer 出队与 Pulse 记账；推荐奖励复用内容周奖公开、现有荣誉页和手动发放。流程不写入实际余额，不改变已发券或已完成抽奖。

## Decision

停止新增互动券，既有账本和已形成的待交付回执保留。发布 2.42 闪期望的不可变奖池，保留券期限。周奖发布时冻结最多十人的推荐奖励，并复用管理员手动发放和荣誉页，通过周奖资格计算徽章次数，撤销时停止计入，保留已经登记的发放凭据。金额按分闪整数计算。

## Alternatives considered

仅重设概率仍无法涵盖互动券的最低支出；清理存量券会改变既有权益；复用独立财务结算会改变内容奖的手动发放边界。

## Consequences

300 人每周只领 6 张签到券，按四周和奖项全满估算 29,966 闪。存量券、管理员赠券及概率波动不属于硬上限；已经公布的历史周奖不追发推荐奖励。后台只登记手动发放，名单不公开。

## Verification

六档权重与 2.42 精确期望、按分闪分配已用单元测试核对。隔离 MySQL 验证老券待交付保留、10 人上限、公布和登记重放、伯乐累计、撤销后不计与公开名单隐私。前端验证六档配色边界、预设及荣誉展示。
