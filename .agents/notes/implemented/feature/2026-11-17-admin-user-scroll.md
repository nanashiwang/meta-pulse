# Agent Note: 用户管理横向查看

Status: implemented

## Problem

用户管理宽表超出可视范围，筛选与列选择不易完整查看，已到账闪与EXP换行增加行高。用户要求同行展示并提供便于拖动的横向进度条。

## Decision

原生用户列表补丁为筛选按钮增加独立class，奖励单元格将换行替换为分隔符。分类按钮保持一行可横向滚动，列选择菜单限高滚动。插件在表格前增加原生range滑条，与table-responsive的scrollLeft双向同步，ResizeObserver跟随表格与容器宽度，切离页面清理。无溢出时隐藏，保留原生表格滚动和右侧操作列。

## Alternatives considered

压缩全部列会降低可读性；只保留表格底部滚动条在长名单中不易访问。因此采用顶部sticky滑条和原有滚动容器，不改查询或列设置持久化。

## Consequences

仅改变布局，不修改用户数据、排序、奖励或权限。需要forum重建。桌面窄窗口与手机均可拖动，range支持键盘操作。

## Verification

全部论坛补丁零模糊应用通过；上游Prettier格式化后生成补丁。浏览器在1280/390px模拟真实列表结构验证分类横向滚动、表格与滑条同步、奖励同行和无视口溢出；资源闭包及滑条边界测试通过。
