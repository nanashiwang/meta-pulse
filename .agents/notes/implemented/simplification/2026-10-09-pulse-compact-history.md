# Agent Note: Pulse 隐藏概率并收起奖励记录

Status: implemented

## Problem

用户要求不展示奖池概率，把长奖励记录收成入口，并去掉抽奖主体前的面包屑、标题和介绍，减少权益页占位。当前公开奖池与完整历史表占据抽奖面板之后的大量高度。

## Decision

删除用户端奖池展示；保留规则读取用于签名选择、额度资格和安全重试，管理员仍可配置并预览概率。奖励记录复用当前页面的原生 details，默认收起，点击「查看奖励记录」展示原金额、到账状态、时间和编号。刷新权益时保留当前展开状态，状态轮询继续更新表内到账状态，不额外持久化私人数据。

抽奖面板直接作为已绑定用户的页面主体，面板内标题承担 h1；介绍收进标题旁的原生 details 问号提示，点击或键盘展开，Escape、点外部或焦点离开时关闭。复用已有介绍和动画模块，交互监听随 View 清理；Pulse 加载骨架同步隐藏大标题与提示占位，登录、绑定和错误提示保持明确。

## Existing capabilities and note review

复用 /pulse、已有规则折叠与奖励查询/状态更新，无新路由、接口或权限。

- [50% 预设](../../implemented/feature/2026-10-09-pulse-fifty-percent-preset.md)：部分重叠，仅替代用户概率展示决定，保留管理员预设与数学计算。
- [统一规则](../../implemented/feature/2026-10-09-pulse-current-reward-rule.md)：部分重叠，仅收起展示，原签名选择、期限、重试继续有效。
- 加载壳和动画笔记：无关，私人页面不缓存与结果演出保持原边界。

## Alternatives considered

- 独立奖励记录页面：能独立分享地址，但需要新增路由及重复身份/加载处理；当前原生折叠入口足够满足查看需求。
- 仅用 HTML title 悬停说明：实现更少，但手机和键盘不易查看完整介绍，改用可点击的原生 details。
- 点击时才读取奖励记录：可少一次首屏查询，但当前历史查询同时恢复上次结果并驱动待到账轮询，保持现有读取以避免削弱恢复。

## Verification

正式前端测试与构建、博客构建通过；本地生产壳使用 50 条受控记录验证默认关闭、键盘展开、手动刷新与抽奖完成后保留展开状态、到账状态更新，以及 390px 中文暗色和 320px 英文表内滚动。空记录、资格和失败提示通过既有回归验证。截图位于 `output/playwright/compact-pulse-*.png`，不代表生产普通账号验收。

## Consequences

问号介绍经桌面与 390px/320px、中英文、深浅主题浏览器验收：默认隐藏、点击及 Enter 展开、Escape 返回焦点、点击或 Tab 离开关闭；抽奖继续只生成原 Action。加载脚本或演出模块失败降级与未绑定入口另行检查。截图位于 `output/playwright/pulse-help-*.png`。

折叠仅减少视觉占位，不减少记录接口负载；规则接口仍返回服务端数据，本次不是 API 信息权限调整。
