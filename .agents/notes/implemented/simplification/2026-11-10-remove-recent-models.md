# Agent Note: 移除近期新模型展示

Status: implemented

## Problem

用户认为刚加入的近期新模型模块没有用途，要求移除。

## Decision

删除首页近期新模型卡片、全部更新链接与专属样式，不恢复原侧栏列表。复用现有综合榜排序和筛选；保留只读 API 的 recent 字段，避免为展示删除扩大接口变更。

## Alternatives considered

恢复侧栏可以继续显示近期模型，但不符合移除模块的要求；同时删除后端字段可少量减少响应体，但会改变 API 契约，超出这次展示裁剪范围。

## Related notes

[模型页精简](../../implemented/simplification/2026-11-10-model-pages.md)的近期新模型卡片决定被本决定取代，其综合榜分页排序和旧链接兼容继续适用。模型情报独立服务提案仅部分重叠，不改变其数据边界。

## Consequences

中英文首页不再出现近期模型卡片或全部更新入口；现有模型页、完整社区前端测试与静态构建通过。首页不再提供近期发布快捷入口，用户仍可通过综合榜发布时间筛选查看模型。后端 recent 字段仍供兼容读取，不改变数据源和同步行为。
