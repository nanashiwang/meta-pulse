# Agent Note: 精简模型榜展示与移除方法页

Status: implemented

## Problem

用户要求移除首页、完整榜与开放权重榜顶部介绍，以及计算方法页面。

## Decision

删除三种榜单的 hero 和方法页入口及渲染；旧地址兼容跳转首页。保留详情来源与服务端方法元数据，避免扩大为数据采集或评分变更。

## Alternatives considered

只隐藏导航能保留旧地址，但无法满足删除页面的要求；返回 404 会使旧书签失效，采用首页兼容跳转。

## Consequences

中英文榜单不再显示 hero、更新时间或方法入口，筛选和数据表保留，旧地址经 Nginx、History 和 hash 兼容返回首页。榜单不再直接显示更新时点，详情保留来源。

完整社区测试、静态构建、模型页与路由回归以及笔记验证通过。已有独立服务提案与来源评分笔记只部分重叠，仍保留其架构与评分决定。
