# Agent Note: 精简模型榜展示与移除方法页

Status: implemented

## Problem

用户要求移除首页、完整榜与开放权重榜顶部介绍，以及计算方法页面。

## Decision

模型评分榜首页的综合榜复用完整榜的服务端数据、筛选、排序和分页；移除独立完整榜入口，旧路径兼容同一合并页。所有可排序列显示双向符号，当前列显示实际数值升降方向（价格默认从低到高）。排序与筛选重置页码，翻页保留条件；保持领先卡片和 FAQ。近期新模型复用 `/home.recent` 的 15 天内最新 6 条记录，提升为综合榜上方独立卡片区，展示厂商文字标识、模型名和日期。卡片打开站内详情，全部更新打开 LLM Stats 的公开动态页；移动端在长表格之前可见。

删除三种榜单的 hero 和方法页入口及渲染；旧地址兼容跳转首页。保留详情来源与服务端方法元数据，避免扩大为数据采集或评分变更。

## Alternatives considered

仅保留侧栏文字列表改动最少，但手机端会落在长榜单之后；独立卡片区让近期发布可直接发现。另建动态 API/页面能承载完整事件流，但当前只要求近期模型，复用已具备的筛选和外部全部更新入口即可。厂商用文字缩写标识，避免依赖第三方图片热链。

保留预览并跳转完整榜虽无需额外首页请求，但重复入口不符合用户要求；直接在浏览器给预览排序无法覆盖全量数据，因此复用既有 `/leaderboard` API 与表格，不新增后端实现。

只隐藏导航能保留旧地址，但无法满足删除页面的要求；返回 404 会使旧书签失效，采用首页兼容跳转。

## Consequences

中英文榜单不再显示 hero、更新时间或方法入口，筛选和数据表保留，旧地址经 Nginx、History 和 hash 兼容返回首页。榜单不再直接显示更新时点，详情保留来源。

完整社区测试、静态构建、模型页与路由回归以及笔记验证通过。已有独立服务提案与来源评分笔记只部分重叠，仍保留其架构与评分决定。
