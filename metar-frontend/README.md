# METAR · 简洁展示版前端

**版本：1.1.0 · 设计日期：2026-09-07**

把 METAR 做成一个“值得浏览、便于参与、能积累关系”的 AI 用户与开发者社区。社区是主要入口，知识库沉淀内容，Pulse 是与真实 API 使用关联的辅助权益。

这是一份全新、独立的前端原型，不是现有仓库的补丁，也不是已经接入生产的应用。没有修改 `nanashiwang/meta-pulse` 或线上 `metar.uk`。

## 立即体验

用现代浏览器打开 **`index.html`**。页面、样式、脚本和 SVG 图标全部内置，没有 npm 安装步骤，没有外部字体和 CDN 依赖。

默认打开 `index.html`，不显示宣传引导卡片、首页欢迎横幅和底部演示工具栏。

开发验收请打开 **`preview.html`**；其中保留底部三组演示工具：

- **身份**：访客、未绑定社区会员、已绑定会员、运营管理员。
- **状态**：正常、加载中、空状态、Pulse 服务降级。
- **页面地图**：查看 43 个页面路由入口，包括筛选与绑定冲突示例。

支持浏览器前进、后退和 Hash 深链接。URL 中的 `#/...` 是原型导航，不是最终生产路由。

浏览器允许时，草稿、收藏、演示记录与配置会写入本机 `localStorage`。存储被限制时自动退回当前会话内存，关闭页面后可能丢失。不要在原型中输入真实密码、API Key 或敏感数据。

### 建议走一遍的流程

**社区**：发现 → 问题详情 → 赞同 / 回答 / 收藏 → 我的收藏。

**创作**：发布 → 保存草稿 → 草稿箱继续编辑 → 提交 → 切换管理员 → 内容审核。

**新人**：切换访客 → 独立注册 → 验证页演示 → 关注话题 → 进入社区。

**权益**：未绑定会员 → 个人设置 / 账号绑定 → 确认演示绑定 → Pulse → 开启 → 回馈记录 → 模拟查询原 Grant 已到账。

**运营**：切换管理员 → 导航与入口 → 调整名称 / 开关 / 排序 → 保存 → 查看导航变化 → 操作审计。

**异常**：切换 Pulse 服务降级 → 开启入口禁用 → 问答与本地登录仍然可用。

## 真正可以操作的内容

搜索和筛选、问题与文章跳转、关注话题、赞同、回答、问题和文章收藏、内容草稿、编辑预览、本地提交和审核、独立注册 / 登录流程演示、可选绑定与冲突状态、通知已读、资料和偏好保存、Pulse 单次开启与原结果查询、内容奖励审核、原 Grant 撤销示例、工单提交与处理、导航配置、公开 HTTPS 入口校验、JSON 导出、深浅色切换。

所有写操作只改变本地示例数据。注册不创建真实账号，邮件不发送，帖子不上线，Pulse 不发放真实额度，配置不更新线上系统。

## 明确保留的业务边界

**Answer** 管理社区身份和内容；**new-api** 管理 API 身份、调用和资金；**Pulse** 管理调用后的权益；**VitePress** 管理知识库长文。

未绑定用户仍能独立注册、登录、发帖、回答和收藏。绑定是一对一的可选关系，不提供普通自助解绑或换绑。发帖、回答和点赞不产生贡献值或脉冲券。内容奖励另行审核，使用独立预算。等级不带来社区治理权限。

**特别注意：原型在同一个 HTML 中演示 Pulse 与后台，并不意味着可以在生产社区网关直接代理 Pulse。** 上线适配方式见交接说明。

## 如何交给开发团队

先读 `docs/HANDOFF.md`，再按 `docs/route-manifest.json` 映射现有服务。把它当作页面结构、交互状态和视觉规范，而不是一键覆盖现有 Answer / VitePress 的生产包。

外部控制台、正式 Pulse 操作页、API 文档、监控状态页面的地址默认未配置。仓库读取未确认这些入口的精确生产路径，因此没有猜测 URL。原型后台已经提供配置表单、未配置提示和二次确认跳转。

修改拆分源码后，在本目录执行：

```bash
python3 build.py
```

即可重新生成单文件 `index.html` 与开发验收入口 `preview.html`。构建只依赖 Python 标准库。原型本身不依赖 Python。

## 核验范围

已通过 43 个路由入口的桌面 / 手机渲染检查与 19 组本地交互测试。没有检测到脚本异常或外部网络请求。测试方式与未覆盖项详见 `docs/QA.md`。

当前环境无法打开生产站点，所以没有把线上视觉、真实接口返回、邮件送达、真实资金到账或生产登录冒充已验收。项目定位与系统边界沿用 v1.0 交接记录；v1.1 只修改已有前端交付物，没有重新审计生产站点或项目源码。
