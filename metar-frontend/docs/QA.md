## 测试方法与限制

测试通过 Playwright 的 `page.set_content()`，将最终生成的 `index.html`（展示检查）和 `preview.html`（含角色切换的交互回归）加载到独立隔离文档中，随后使用原生 Hash 路由与实际 DOM 点击完成检查；没有修改浏览器安全策略。

因此，本次验证的是页面渲染、Hash 变化、DOM 行为和本地状态转移。**没有验证实际文件打开、HTTP 静态托管、页面刷新后的跨会话存储或生产域名访问。** 隔离文档不能使用 localStorage，测试同时确认了存储不可用时的会话内存降级。源码中的持久化保存仍需在目标浏览器的真实页面来源上回归。

仅使用了 Chromium 自动化，不代表已通过 Safari、Firefox、实际手机或完整无障碍审计。颜色对比、屏幕阅读器、键盘边界和目标浏览器差异仍需生产前专项验收。

## 19 组已验证交互

1. 访客需要参与时，进入独立社区登录，完成演示登录后返回编辑器。
2. 注册 → 邮箱验证演示 → 新手引导；登录密码不写入状态。
3. 搜索、内容类型筛选及无结果恢复。
4. 问题和文章收藏，包括“只剩文章收藏”的情况。
5. 赞同与回答保留在本地，但不增加 Pulse 券。
6. 草稿 → 编辑 → 提交待审 → 访客不可见 → 管理员审核。
7. 可选绑定需明确确认，不提供普通自助解绑。
8. 绑定冲突时拒绝覆盖。
9. Pulse 确认 → 消耗一次券 → 稳定动作 ID → 查询原 Grant，重复确认不重复扣券。
10. Pulse 降级禁用权益操作，但不阻断社区浏览与独立登录。
11. 内容奖励审核不增加贡献券、不重复审批、不批准不合格候选。
12. 导航名称与开关保存后立即更新导航，并写入演示审计。
13. 公开 HTTPS 入口配置、离站确认及带凭据 URL 的拒绝。
14. 工单本地提交 → 运营处理；不修改账号。
15. 撤销演示新增反向记录，原金额保持不变。
16. 通知全部已读与未读为空状态。
17. 键盘搜索、对话框焦点约束与 Escape 关闭。
18. 普通会员访问运营页面出现独立权限提示。
19. 存储不可用时，页面与本地编辑仍可继续。

这是前端演示语义，不是生产权限、财务幂等、账本或数据库并发测试。例如第 9 项验证的是 UI 不重复发起演示动作，不能取代服务端事务、重放与并发测试。

## 复跑方式

原型打开不需要安装测试依赖。仅开发者复跑自动化时需要 Python、Playwright 与 Chromium：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
python3 build.py
python3 tests/smoke.py
python3 tests/interactions.py
python3 tests/presentation.py
```

脚本优先采用 `CHROMIUM_PATH` 指定的浏览器，其次查找系统 `chromium`，否则采用 Playwright 自带浏览器。安装是否可用取决于开发环境的网络与权限；不能为运行测试关闭组织浏览器策略。

## v1.1 简洁展示专项

首页在 1440、1024、768、390、375、320px 六种视口宽度下核验：指定文案与卡片不出现、默认不显示演示栏、精选卡片上下边缘相等、卡片外缘和问答列表边缘相等、没有横向溢出。手机主导航贴合底部，不残留演示工具栏空位。

问答、话题、问题详情、文章详情、发布、Pulse 和个人主页七条路线检查：已移除的引导/推荐卡片没有再次出现，无空侧栏占位；问答和发布在无侧栏时扩展为单列。另验证侧栏 Pulse 入口可跳转，以及开发入口与首页标题配置仍可用。
