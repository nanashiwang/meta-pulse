# METAR 正式前端

此目录是 `metar-frontend/` 视觉原型对应的**生产适配层**，与原型的本地 mock 完全分离。

当前接通：

- Apache Answer 实时问题列表、详情、回答、话题和搜索；
- Answer 当前用户、个人资料、收藏、通知和 Connector 绑定状态；
- 默认头像显示用户名首字符；已在 Answer 上传的同源头像正常展示，加载失败自动回退首字符；
- Answer 原生登录、注册、账号找回、邮箱激活、发布与写操作入口；
- VitePress 知识库入口；
- 本人 Pulse 券、奖池、抽奖、奖励记录，以及未登录、未激活、未绑定和服务不可用状态；
- 社区管理员 `/#/admin/pulse` 配置入口：服务连接、额度单位、运行开关、角色密钥与上一密钥轮换槽。
- 右上角中文 / English 切换，默认中文；静态界面、无障碍标签、日期数字与 API 请求语言同步切换，帖子与用户资料保留原文。

当前不伪造：Pulse 等级、余额、券、奖励、运营权限、工单和审核结果。它们必须在对应服务端接口完成后再开放。

用户可通过“个人空间 → 编辑 Answer 资料 → 头像 → 自定义”上传并保存图片。静态壳层只读取 Answer 保存的头像，不写入用户资料；Gravatar 和其他外部图片使用首字符替代，保持现有同源图片策略。

语言偏好保存在同源浏览器 `localStorage` 的 `metar-language`，仅接受 `zh_CN` / `en_US`，与 Answer 页面共享；不更改用户数据库设置。浏览器存储不可用时仍支持当前页面切换。语言模块只翻译显式标记的界面文案，不扫描或替换用户生成内容，也不需要放宽 CSP。

构建：

```bash
python3 build.py
```

部署脚本会把产物构建到 `sites/blog/docs/.vitepress/dist/metar/`，由现有社区网关静态托管。公开配置来自 `config.production.json`，只允许同源路径或无凭据的 HTTPS 外部地址，禁止写入任何密钥。稳定资源路径强制浏览器重新验证，避免更新后首页与旧版 JS/CSS 混用。

管理入口只对 Answer 返回正常且已激活的 `role_id=2` 管理员显示，所有读写仍由服务端实时鉴权。首次使用需在 Answer 插件中配对 `admin_hmac_secret`。管理请求只走同源 `/metar/api/admin/pulse/*`；已保存密钥只显示是否配置，空白保留。新密钥与保存草稿仅存当前页面内存，不写入浏览器存储。版本冲突保留输入并要求重新读取核对；保存结果不确定时以原 payload 和幂等键恢复，刷新或离开页面会清除草稿。
