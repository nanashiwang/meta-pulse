# METAR 正式前端

此目录是 `metar-frontend/` 视觉原型对应的**生产适配层**，与原型的本地 mock 完全分离。

页面使用 History 普通路径：`/latest`、`/topics`、`/question/:id`、`/me/bookmarks`、`/me/notifications`。旧 `/#/...` 链接自动转换；Nginx 深链接白名单与前端路由同时维护，不能把 Answer 的 `/questions`、`/users/*` 或接口改成全站静态回退。首页使用紧凑列表，不展示介绍统计卡和右侧推荐卡。

当前接通：

- Apache Answer 实时问题列表、详情、回答、话题和搜索；
- Answer 当前用户、个人资料、收藏、通知和 Connector 绑定状态；
- 默认头像显示用户名首字符；已在 Answer 上传的同源头像正常展示，加载失败自动回退首字符；
- Answer 原生登录、注册、账号找回、邮箱激活、发布与写操作入口；
- VitePress 知识库入口；
- 本人 Pulse 券、奖池、抽奖、奖励记录，以及未登录、未激活、未绑定和服务不可用状态；
- Pulse 核心约 3.9 秒的汇聚、蓄能、裂变和奖励卡揭晓，支持翡翠/紫蓝光效、跳过、系统减少动态效果；服务端结果未返回时保持蓄能呼吸与粒子环绕，结果与到账状态分别展示。
- 社区管理员 `/admin/pulse` 配置入口：服务连接、额度单位、运行开关、角色密钥与上一密钥轮换槽。
- 右上角中文 / English 切换，默认中文；静态界面、无障碍标签、日期数字与 API 请求语言同步切换，帖子与用户资料保留原文。

当前不伪造：Pulse 等级、余额、券、奖励、运营权限、工单和审核结果。它们必须在对应服务端接口完成后再开放。

API 额度在奖励卡、奖池、奖励记录及后台单位提示中统一标为 `⚡️`，中英文一致，例如 `1 ⚡️`。数字继续按既有 `quota_per_unit` 精确换算，缺少有效换算配置时保留原始 `quota` 标识；社区经验仍使用 `EXP`。

Pulse 演出提供单抽和五连抽：桌面五张卡横排，窄屏排列为三张加两张，规则说明默认折叠。白光对应 EXP，额度的蓝、紫、金、红光分别对应小于 0.5、0.5 起、2 起、10 起的额度单位。光效不影响概率，最高档控制整体爆发，各卡分别显示其档位；保留跳过偏好、减少动态效果和后台发奖。

五连抽通过原有接口顺序发送五个普通 Action，发起前持久保存五组编号，部分成功后不回滚已确认奖励。刷新与重进页面只读查询这些原编号，点击继续后才补完未确认请求；明确拒绝会停止剩余次数，网络不确定时不能另起新抽奖。回归覆盖丢失第三次响应、重复恢复、切页暂停、部分拒绝、旧版单抽记录与存储失败。

用户可通过“个人空间 → 编辑 Answer 资料 → 头像 → 自定义”上传并保存图片。静态壳层只读取 Answer 保存的头像，不写入用户资料；Gravatar 和其他外部图片使用首字符替代，保持现有同源图片策略。

语言偏好保存在同源浏览器 `localStorage` 的 `metar-language`，仅接受 `zh_CN` / `en_US`，与 Answer 页面共享；不更改用户数据库设置。浏览器存储不可用时仍支持当前页面切换。语言模块只翻译显式标记的界面文案，不扫描或替换用户生成内容，也不需要放宽 CSP。

构建：

```bash
python3 build.py
```

部署脚本会把产物构建到 `sites/blog/docs/.vitepress/dist/metar/`，由现有社区网关静态托管。公开配置来自 `config.production.json`，只允许同源路径或无凭据的 HTTPS 外部地址，禁止写入任何密钥。稳定资源路径强制浏览器重新验证，避免更新后首页与旧版 JS/CSS 混用。

公开浏览与身份查询并行，个人、绑定、权益和管理页等待身份确认；身份返回只更新页头，避免重载已出现的内容。站内切页保留导航与搜索输入，浏览器返回恢复原列表位置，过期导航响应不改变当前内容或滚动。列表加载显示静态骨架，320px 窄屏保留账户入口并自动露出当前筛选。

问题列表、标签和搜索结果在当前页面内存中最多保留 24 项、15 秒，按 Answer token 与语言隔离并合并同一在途请求。重试、主动搜索、身份变化与 bfcache 恢复会清理；失败不缓存。身份、权限、绑定、个人信息、通知、成长、Pulse 财务和后台接口始终直接读取，服务状态页也使用实时请求。成长和管理模块按需加载，公开作者等级在内容显示后的空闲阶段增强。Nginx 对 METAR 静态脚本、样式和公开知识库启用 gzip，同时保留资源更新验证。验收数据见 [用户体验验证](../../docs/UX_PERFORMANCE.md)。

`pulse-core.js` / `pulse-core.css` 仅在已登录、已激活并绑定的用户进入权益页时加载；资源加载失败或超过 5 秒未完成时保留普通开启入口。Canvas 空闲和演出结束后停止逐帧绘制，等待 Action 时保持轻量呼吸；切换页面清理观察器与监听器，减少动态效果或切入后台会跳过视觉演出，但仍等待真实结果。光效偏好保存在同源 `localStorage` 的 `_metar_pulse_palette`；左下角“跳过动画”复选框使用 `_metar_pulse_skip_animation`（`1` / `0`），勾选立即跳过当前演出并用于后续抽奖，存储不可用时保留当前页面选择。

奖励卡只使用服务端返回的奖项类型、整数数量和状态，不持久化奖项或券余额；原请求恢复继续使用已有 `PulseOperation`。演出完成后局部刷新权益与记录，刷新失败保留结果卡并暂停下一次开启，直到重新确认最新资格。发放中不阻塞下一次开启；页面对奖励状态执行最多 12 次只读查询（前 5 次间隔 2 秒，之后 5 秒），不重放 Action、不改变券余额。隐藏或切页停止后续查询，迟到响应不能覆盖新的导航、抽奖或主动刷新；未完成仍可手动刷新。

管理入口只对 Answer 返回正常且已激活的 `role_id=2` 管理员显示，所有读写仍由服务端实时鉴权。首次使用需在 Answer 插件中配对 `admin_hmac_secret`。管理请求只走同源 `/metar/api/admin/pulse/*`；已保存密钥只显示是否配置，空白保留。新密钥与保存草稿仅存当前页面内存，不写入浏览器存储。版本冲突保留输入并要求重新读取核对；保存结果不确定时以原 payload 和幂等键恢复，刷新或离开页面会清除草稿。

导航布局：左侧仅保留社区内容与帮助入口；个人空间、成长、收藏、绑定、设置与管理员入口统一放在右上角头像菜单。通知铃铛独立保留，未读状态来自 Answer；头像菜单等级来自公开社区经验接口，获取失败时省略。Answer 原生头像菜单同步增加这些入口，保留原生退出登录处理与权限边界。
