# 社区加载与导航验收（v0.2.28）

对照为 v0.2.27 的 `9fb64ba`，优化对象为 METAR 生产壳层与社区网关。全部浏览器数据使用隔离的本地 Answer/Pulse 响应；没有读取生产用户数据、真实扣券或执行生产部署。

## 固定延迟对比

桌面 Chromium、1366 × 900，身份接口固定等待 800ms，列表接口固定等待 350ms；每版执行三次独立页面加载。通过页面内 MutationObserver 记录首批讨论行进入 DOM 的时刻，脚本体积取浏览器 Resource Timing 的解码后大小。

| 指标 | v0.2.27 | v0.2.28 |
| --- | --- | --- |
| 列表显示时间（三次） | 1198 / 1213 / 1207ms | 396 / 395 / 393ms |
| 列表显示中位数 | 1207ms | 395ms |
| 首页脚本请求（包含延后显示的作者等级） | 13 | 10 |
| 首页脚本未压缩总量 | 约 213KB | 约 167KB |
| 列表 → 标签 → 返回列表 | 重查列表，搜索输入和位置丢失 | 15 秒内复用原列表，保留输入与位置 |

这些是固定接口延迟下的对照，不代表生产站点的 LCP、INP、综合评分或真实用户延迟。主要收益来自去除身份与公开内容的串行等待，并减少非当前页面所需脚本。

## 网关实测

使用真实 `nginx:1.27-alpine`、仓库网关配置和生产构建产物验证 gzip：主脚本约 66KB → 23KB，样式约 61KB → 18KB，知识库首页约 10KB → 3.4KB。解压后的内容与原资源一致，响应带 `Vary: Accept-Encoding`，稳定资源仍为 `Cache-Control: no-cache`，ETag 条件请求返回 304。

## 交互与边界

- 身份慢或失败时公开内容可读，私人入口等待确认；跨标签身份变化移除旧私人内容。
- 页头与搜索草稿保留，加载和身份更新不抢输入焦点；旧导航不会覆盖新内容或滚动。
- 公开内容缓存按令牌、语言、路径与参数隔离，最多 24 项、15 秒；在途请求合并，失败可重试。身份、绑定、权限、私人及财务数据不进入缓存。
- 管理权限门槛、模块依赖顺序、模块下载失败重试、成长模块失败时的个人资料展示均已检查。
- 作者等级增强、Pulse 真实结果揭晓、中英文、深浅主题、320px / 390px 窄屏、账户入口和手机导航均在浏览器检查。

自动检查：`make test vet build`；真实网关检查：构建博客与社区后运行 `python3 deploy/nginx/test-seo.py`。
