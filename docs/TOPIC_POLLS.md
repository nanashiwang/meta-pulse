# 帖子投票

## 使用方式

1. 在“新建话题”的表单底部展开“添加投票（可选）”，勾选附带投票。
2. 填写题目和2—10个不同文字选项，选择单选或最多可选几项，持续1/3/7/30天（默认7天）。
3. 正常发布帖子。投票显示在正文之后、回答区之前。已发布话题的详情页不提供新建入口；若发帖后投票保存失败，仅显示对应的恢复提示。
4. 已登录、邮箱已验证且状态正常的账号可参与，截止前可修改选择。
5. 投票后或结束后可以看人数及比例，不公开谁选了什么。多选比例按参与人数计算，合计可超过100%。
6. 作者可提前结束，结束后不能恢复；题目、选项、限选数和截止时间在发布后不可编辑。

## 失败与可见性

帖子和投票分两步保存。若帖子已发布而投票未确认，详情显示恢复提示，点击“重试保存原投票”，不要再发布一遍帖子。投票/改票超时使用“重试原请求”；若其他标签页已改票，刷新获取当前选择后再提交。隐藏、删除或待审核的帖子不会公开显示投票；帖子关闭后不接受新票。

## 部署

投票数据存在Answer数据库的metar_topic_poll、metar_topic_poll_ballot、metar_topic_poll_command表，插件首次初始化创建，使用现有论坛数据库备份。需要构建新版forum，原生Ask补丁与插件资源必须一起更新。无需修改Pulse、new-api或奖励规则。投票不发放经验、券、闪电或声望。

## 验证

Go: go test ./services/forum-plugin/user-center-pulse ./services/forum-plugin/user-center-pulse/polls

数据库并发测试需要独立、可销毁的 _test 数据库和 POLLS_INTEGRATION_DSN；测试会重建其中的投票、用户和帖子测试表，禁止指向生产。CI在MySQL8.0/8.4创建专用community_polls_test后执行。
