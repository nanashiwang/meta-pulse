# 社区经验与成长等级

社区经验（EXP）累计不按月清零，记录论坛参与；与 Answer 声望、Pulse 终身贡献值分别记账。不兑换余额、贡献值或脉冲券，不授予治理权限。专家、导师等专业称号另行审核。

|等级|称号|累计 EXP|
|---|---|---:|
|Lv.0|新朋友|0|
|Lv.1|初来乍到|150|
|Lv.2|活跃成员|600|
|Lv.3|热心交流者|1,750|
|Lv.4|社区熟面孔|4,500|
|Lv.5|资深参与者|10,000|
|Lv.6|社区共建者|22,500|
|Lv.7|长期贡献者|45,000|
|Lv.8|社区同行者|90,000|

## 默认获取规则

|行为|单次 EXP|限制|
|---|---:|---|
|签到|2|北京时间每日一次；连续第 7 天起每日 3 EXP，断签只重置连续天数|
|有效问题|5|每日一次|
|有效回答|8|每日两次|
|收到有效点赞|2|每日最多 20 EXP；同一点赞者对同一作者每日最多三次|
|被提问者采纳|20|每日一次；排除自问自答|
|管理员精选|50|每内容一次、每用户每月最多四次；独立于常规每日上限|

常规行为每日合计上限 60 EXP。有效点赞者须邮箱已验证、正常账号、注册至少七天，且点赞发生时达到 Lv.1。自己的点赞不计经验。所有经验领取均要求 Answer 本地账号正常且邮箱已验证，不要求绑定元衡 API。

问题、回答、点赞、采纳经过 24 小时观察，采集和复核通过后入账。每日限额按观察到期日（Asia/Shanghai）归属，服务短暂中断后的补录不挤占恢复当天限额。撤赞、取消采纳、删除或隐藏内容会追加撤销流水；恢复内容或反复操作不重新奖励，撤销不返还当天额度。关闭但仍公开的问题保留有效性。

部署首次初始化记录启用时间，旧内容不追溯奖励。采集器每分钟有界扫描，并保存游标；大规模历史库需多轮扫描。账号未激活期间被扫描的行为不补发。已进入观察期的奖励固定原规则金额和上限，修改规则只影响之后首次采集的事件。

## 页面与运营

- `/me` 展示成长卡；`/me/growth` 提供签到、当前等级、升级进度、规则、等级表、升级通知、待发放记录和分页流水。
- 公开作者旁展示社区等级。Lv.3 头像框、Lv.5 个人主页主题、Lv.6–8 进阶装扮为展示权益，不控制发帖或管理权限。
- `/admin/growth` 仅开放给实时校验通过的 Answer 管理员。规则按版本 CAS 保存；精选、人工调整需原因和幂等请求编号，原因对用户可见。
- 人工调整最大单次 ±100,000 EXP，不允许扣至负值。若此后来源撤销导致账本净值为负，前台显示 0/Lv.0；后续新增经验先抵消差额，账本仍保存完整事实。
- 升级通知每个等级最多一次；扣回导致降级后，未达到门槛的装扮自动降级为默认展示。

## 存储、安装与恢复

插件使用已有 `FORUM_BINDING_GUARD_DSN` 连接 Answer MySQL，单独连接池，不依赖 Pulse、Redis 或可选绑定配置。首次调用经验接口初始化 `metar_exp_*` 表和追加式历史保护触发器；需要 CREATE TABLE、CREATE TRIGGER 权限。失败时经验功能返回不可用，论坛原生登录、浏览和写内容继续工作。

`metar_exp_ledger` 为经验事实源；`metar_exp_account.balance` 为派生快照。`event` 保存事件身份、固定规则和撤销状态；`config/audit` 保存配置版本与操作审计；`cursor` 为采集进度；`notice` 为通知投影。账本和审计禁止 UPDATE/DELETE，修正只新增记录。数据库备份须与 Answer 一起覆盖这些表；回滚应用无需删表或重置经验。

对账可按 `user_id` 聚合 `SUM(metar_exp_ledger.delta)` 与 `metar_exp_account.balance` 比较，修复快照需停写、备份后按聚合值重建，不能修改历史金额。签到状态可从 `event.kind='checkin'` 的连续 `earned_day` 重建。装扮偏好和通知已读状态单独备份。

内部 `AwardPulse` 接收可信奖励编号和整数 EXP，按奖励编号去重；先撤销后收到迟到发奖时保留撤销墓碑。浏览器无直接发经验接口。此接口本身不代表已配置或开放含经验的 Pulse 奖池。

## 验证

`make test-community`、`go test ./services/forum-plugin/user-center-pulse/...`；专用测试库以 `_test` 结尾，使用 `GROWTH_INTEGRATION_DSN=... make test-growth-integration` 执行真实 MySQL 并发签到、来源撤销、冻结规则、精选、管理员幂等、资格限制、历史防篡改和账本对账测试。集成测试会重建该专用库内的测试表，不可指向生产库。
